# Church of Bacchus

Static reconstruction from the owner's supplied Wix screenshots and original artwork. No packages, build process, Wix runtime, tracking scripts, or paid hosting dependency.

## Local preview
Run `python -m http.server 8080` from this directory, then open http://localhost:8080.

## GitHub Pages
Publish this directory as its own repository. In Settings → Pages choose Deploy from a branch, `main`, `/ (root)`.
Do not upload the source ZIP or phone screenshots into the public repository; only this site's files belong there.

## Remaining launch details
- Current PayPal donation URL, Patreon URL, and public Bitcoin receiving address must be supplied before enabling payment links. Existing buttons open an inquiry email; no old wallet address was copied.
- Contact form composes an email in the visitor's mail app; it does not send from a server. A hosted form endpoint is needed for direct submission or a mailing-list subscription. No fake subscription form is included.
- The NFT artist invitation is preserved from the original; confirm whether it is still current.
- Configure churchofbacchus.org in Pages before updating DNS. No CNAME is committed yet so the initial github.io preview remains usable.
- Recommended secondary domain: redirect churchofbacchus.com to https://churchofbacchus.org through the registrar.
